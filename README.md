Python Unit Converter

Project Description

The Python Unit Converter is a simple desktop application developed using Python and Tkinter. It allows users to convert values between different units of measurement through an easy-to-use graphical user interface.

Features

* Length Conversion: Meter, Kilometer, Centimeter, Millimeter, Mile and Foot.
* Weight Conversion: Kilogram, Gram, Milligram and Pound.
* Temperature Conversion: Celsius, Fahrenheit and Kelvin.
* Simple and user-friendly graphical interface.
* Convert and Clear buttons.
* Input validation for incorrect values.

Technologies Used

* Python
* Tkinter
* VS Code

Installation and Execution

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python unit_converter.py

6. The Unit Converter application will open.

How to Use

1. Select a conversion category (Length, Weight or Temperature).
2. Enter the value you want to convert.
3. Select the From Unit.
4. Select the To Unit.
5. Click the CONVERT button to see the converted result.
6. Click CLEAR to reset the input and result.
